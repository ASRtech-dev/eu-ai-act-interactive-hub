## 🎯 Project Overview | Resumen del Proyecto

**🇬🇧 English:**  
The **European Artificial Intelligence Act (Regulation (EU) 2024/1689)** is the world’s first comprehensive horizontal legal framework for AI. This project bridges the gap between complex European statutory law (113 Articles, 180 Recitals, and 13 Annexes) and practical implementation. Built entirely with **semantic HTML5, Europa Component Library (ECL v4) inspired CSS3, and pure Vanilla JavaScript**, it combines rigorous legal citations with a 60fps interactive 3D HTML5 Canvas and accessible UI choreography.

**🇪🇸 Español:**  
El **Reglamento Europeo de Inteligencia Artificial (Reglamento (UE) 2024/1689)** constituye el primer marco jurídico integral y vinculante del mundo sobre IA. Este portal interactivo traduce la complejidad técnica y normativa del texto publicado en el *Diario Oficial de la Unión Europea* (113 artículos, 180 considerandos y 13 anexos) en una experiencia visual clara y rigurosa para ciudadanos, empresas, desarrolladores y juristas, construida **sin dependencias externas** mediante HTML5 semántico, CSS3 institucional y JavaScript nativo con renderizado 3D en `<canvas>`.

## ⚡ Interactive Frontend Architecture

1. **Interactive 3D Geodesic Neural Sphere & 12 EU Stars Canvas (`#product-canvas`)**
   - Custom 3D Fibonacci/geodesic projection engine written in pure HTML5 2D `<canvas>` (`requestAnimationFrame`, HiDPI `devicePixelRatio` scaling up to `2.5x`).
   - Real-time Euclidean mouse/touch hit-testing across the 12 orbital EU stars, paired with full keyboard accessibility (`ArrowLeft`, `ArrowRight`, `Home`, `End`) and `prefers-reduced-motion` compliance.
2. **FLIP-Style Stage Choreography (`#citizens-stage-grid`)**
   - Uses the native **Web Animations API (`Element.animate()`)** to smoothly transition the selected Citizen Protection card to the bottom-left stage while unfolding its detailed statutory drawer to the right and repositioning sibling cards along the top row.
3. **WAI-ARIA Interactive Rollout Timeline (`#governance`)**
   - Full `role="tablist"` / `role="tabpanel"` implementation with roving `tabindex`, keyboard arrow navigation, and live status badge transitions covering all 5 statutory phases (`2024–2027`) plus Article 111 grandfathering rules.
4. **European Visual Identity & Illustrations (`styles.css` & `assets/illustrations/`)**
   - European royal navy (`#001435`, `#003399`) and luminous EU gold (`#FFCC00`) glassmorphism paired with 12 editorial illustrations across all sections and risk tiers.

## 🚀 Quick Start & 1-Click GitHub Pages Deployment

Because the project uses **100% relative asset paths** and **zero build steps**, it can be deployed directly to GitHub Pages in under 60 seconds:

### Deploy to GitHub Pages
1. Push this folder to a new or existing GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: add EU AI Act Regulation (EU) 2024/1689 interactive reference hub"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository, open **Settings** ⚙️ → **Pages**.
3. Under **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)` → click **Save**.
4. Your interactive EU AI Act web app will be live at:  
   `https://<your-username>.github.io/<your-repo-name>/`  
   *(All "GitHub Repo" buttons in the navbar and footer automatically detect your `<your-username>.github.io/<your-repo-name>` domain and link straight back to your GitHub repository!)*
